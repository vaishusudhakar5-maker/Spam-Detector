# 🛡️ Spam Message Detector  
A simple and efficient **Spam Detector Website** built using **Python, Flask, and Machine Learning**.  
This project classifies text messages as **SPAM** or **HAM** (not spam) in real-time.

---

## 🚀 Features  
- 🔍 Detects spam messages instantly  
- 🧠 Machine Learning model (Naive Bayes)  
- 🌐 Simple Flask web interface  
- 📱 Works on Mobile & Desktop  
- 📊 Trained using real SMS spam dataset  
- 💡 Easy to deploy and run locally  

---

## 🛠️ Technologies Used  
- **Python**  
- **Flask**  
- **Scikit-learn**  
- **Pandas**  
- **HTML / CSS**

## 🧠 How It Works  
1. The dataset is cleaned and preprocessed  
2. Text features are converted using **CountVectorizer**  
3. A **Multinomial Naive Bayes** model is trained  
4. The model and vectorizer are saved (`model.pkl`, `vectorizer.pkl`)  
5. Flask loads these files and predicts SPAM or HAM on user input
